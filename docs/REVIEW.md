# Review Guide

Before editing, read `AGENTS.md`, `README.md`, `package.json`, and the files related to the task.

Work on a task branch, not `main`.

Make focused changes and avoid unrelated refactors.

Keep OBS/browser-source performance in mind.

Do not change deployment or environment settings unless explicitly requested.

Use the smallest relevant check. For this project, prefer `npm test`.

Final report should include changed files, what changed, validation result, what was not validated, and manual steps remaining.
