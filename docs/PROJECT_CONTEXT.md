# Project Context

This project is a Netlify-ready OBS/browser-source fortune wheel and stream overlay project for Timur Fearless.

## Priorities

- Keep OBS overlays lightweight and reliable.
- Keep production and custom URLs stable.
- Preserve the existing Netlify/GitHub workflow.
- Avoid exposing private credentials or platform tokens.
- Do not invent chat, donation, sub, winner, or platform data.

## Future expansion

If future work needs persistent storage, moderation dashboard, remote control, or new platform integrations, propose a separate architecture task before adding infrastructure.
